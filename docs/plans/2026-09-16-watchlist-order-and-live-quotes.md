# 自选股分组排序与实时行情刷新方案

## Summary

同时完成两项功能：

1. **系统分组排序**：将“全部”“未分组”与自定义分组统一纳入左侧排序；系统分组仍不可重命名、删除。
2. **自选股行情刷新**：交易时段内，左侧自选股显示行情源返回的最新价和当日涨跌幅，不再使用本地日线收盘价；非交易时段保留最近有效行情并明确更新时间状态。

## Implementation Changes

### 1. 统一保存左侧分组顺序

- 在 SQLite 增加幂等的左侧分组顺序配置表，保存以下 section key：
  - `all`
  - `ungrouped`
  - `group-{id}`
- 扩展 `GET /api/watchlist`，返回 `section_order`。
- 新增 `PUT /api/watchlist/order`：
  - 请求：`{"section_keys":["ungrouped","group-2","all","group-1"]}`
  - 必须包含当前全部系统分组和自定义分组，不能重复、遗漏或包含不存在的分组。
  - 事务内保存顺序；删除自定义分组时同步清理对应排序项。
- 保留旧的自定义分组排序接口兼容：
  - 旧接口继续接受仅自定义分组的排序请求。
  - 内部转换为新的完整 section 顺序，避免破坏已有调用方。
- 前端将“全部”“未分组”和自定义分组渲染为同一个可排序列表：
  - 支持拖到目标标题上半部插入前面，下半部插入后面。
  - 系统分组不显示重命名和删除菜单。
  - “全部”仍保留添加自选入口。
  - “未分组”仍按系统规则计算，不改变股票归属。
  - 保留现有分组内股票拖动排序、折叠状态和失败回滚。

### 2. 增加批量行情快照接口

- 在现有腾讯行情能力基础上增加批量报价解析，优先请求：
  - `https://qt.gtimg.cn/q=...`
- 按应用内证券代码转换为腾讯市场代码：
  - `1Axxxx` → `sh00xxxx`
  - 沪市普通股票 → `sh六位代码`
  - 深市、北交所代码按现有市场映射处理。
- 解析并返回：
  - `symbol`
  - `latest`
  - `previous_close`
  - `change`
  - `change_pct`
  - `quote_time`
  - `source`
  - `status`
  - `error`（单只证券失败时）
- 新增轻量接口 `GET /api/watchlist/quotes`：
  - 默认读取当前启用自选股。
  - 一次批量请求并按应用代码返回报价。
  - 同一股票出现在多个分组时只请求一次。
  - 不触发历史行情同步、缠论计算或分时图重建。
  - 保留上次成功快照；单只失败不影响其他股票。
- 行情快照只作为左栏展示数据，不写入 `market_bars`，避免把实时快照误当成历史 K 线。

### 3. 前端左栏独立刷新

- 扩展 `Stock` 类型，增加行情快照字段和状态：
  - `quote`
  - `quote_time`
  - `quote_status`
  - `quote_source`
- 左栏显示：
  - 最新价
  - 当日涨跌幅
  - 必要时显示行情时间或“数据延迟”
- 新增自选行情刷新控制器：
  - A 股连续交易时段默认每 10 秒刷新一次。
  - 页面隐藏时暂停请求，重新可见时立即刷新。
  - 午休、收盘、节假日降低刷新频率或停止高频刷新。
  - 请求不重叠；上一请求未完成时不再并发发起同类请求。
  - 切换股票、修改分组、股票增删时取消或重置过期请求。
- 刷新只合并更新价格相关字段，不重置：
  - 分组顺序
  - 折叠状态
  - 当前选中股票
  - 主图数据
  - 绘图和指标设置
- 失败策略：
  - 保留最后一次成功价格。
  - 显示“行情延迟”或“更新失败”状态。
  - 没有任何有效报价时显示 `--`。
  - 不使用昨天的日线价格冒充实时价格。
- 当前选中股票的分时图刷新继续使用现有 `/api/chart-data?...timeframe=1` 链路；左栏批量行情与主图分时刷新相互独立。

## Test Plan

### 后端

- SQLite 初始化可重复执行，并兼容已有数据库。
- 系统分组和自定义分组混合排序后顺序正确、刷新后仍存在。
- 排序请求重复、遗漏、未知 section 时返回 `400`，数据库顺序不改变。
- 删除自定义分组会清理排序项；`all`、`ungrouped` 不存在删除接口。
- 批量行情代码映射覆盖：
  - 沪市股票
  - 深市股票
  - 指数别名 `1Axxxx`
  - 多股票批量请求
- 行情解析覆盖正常报价、停牌/空字段、单只错误、整批错误和异常时间。
- 验证行情快照不会写入或修改 `market_bars`、同步记录和缠论结构。

- 系统分组与自定义分组可任意前后拖动。
- 系统分组菜单不出现重命名、删除按钮。

- 测试 10 秒刷新、请求不重叠、页面隐藏暂停、重新可见立即刷新、切换股票取消旧请求。
- 测试行情失败保留旧值、无旧值显示 `--`、多分组重复股票只保留一份快照。

## Assumptions

- 本次采用现有腾讯行情来源扩展，不新增付费行情服务。
- “实时”定义为行情源可提供的近实时快照；第一版默认 10 秒轮询，不承诺逐笔行情或交易所级低延迟。
- 行情源返回的 `latest`、`previous_close` 和 `change_pct` 优先作为展示口径，不混用本地复权日线计算。
- 不改变历史 K 线、分时图、缠论规则、晚间同步任务和现有股票池权威关系。
- 计划执行前需先释放磁盘空间；当前磁盘可用空间约 145 MB，不足以安全运行完整构建和写入新增代码。
