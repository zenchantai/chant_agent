## 二、展示与交互规则

### 1. 按级别展示活动中枢和组成中枢

- 默认打开 L1，显示活动 L1，以及从活动高级中枢的扩张组成关系递归追溯到的 L1。
- 打开 L2、L3 时采用相同规则；不自动打开其他级别。
- 每个“中枢家族＋级别”通常只绘制一个代表修订：优先该级活动修订；否则选正式升级引用的子修订。存在多个合法引用时，按修订时间、修订号、稳定 ID 选择最新者。
- 不遍历绘制全部历史修订，不把失效候选、冲突形成路径或普通旧快照当成组成中枢。
- 矩形继续使用所选修订的固定 `ZD/ZG` 和结构起止时间，不把进入段或 Z 包络画成核心。

### 2. 明确层级关系，避免遮挡

- 活动中枢沿用当前层级颜色；组成中枢使用同级细实线和更低透明度底色。
- 父级先绘制、子级后绘制；同屏重叠时低级边界保持可辨认。
- 标签和详情显示“L1 中枢 #N · L2 的组成中枢”，分别展示结构状态、是否活动及父中枢引用。
- “已升级”不是“候选”，不得用候选虚线表达。
- 保留现有稳定编号，不因分页、层级筛选或展开重新编号。
- 数量提示区分“活动中枢”和“组成中枢”；有组成 L1 时不再提示“无 L1”，改为“无活动 L1，显示 N 个组成 L1”。

### 3. 买卖点精确关联当时的中枢

- 点击买卖点，以其 `center_revision_id` 为唯一直接依据，不能用家族当前 L2 替代原 L1。
- 高亮对应核心，并按现有角色区分进入、核心、Z 延伸、外围及该点引用的离开、回试组件；详情提供可点击的中枢引用和父级关系。
- 若买卖点引用的修订不同于常显代表修订，选中期间临时用精确修订替换该家族同级矩形；取消选择后恢复，避免叠画两份。
- 若对应级别已隐藏，临时显示选中证据并注明“临时证据”，不改动用户图层开关。
- 引用缺失时明确显示“中枢证据缺失”，不得跳转其他中枢作为兜底。
- 多个矩形重叠时，点击优先命中选中证据，其次较低级别，再按屏幕面积和稳定 ID 排序；父中枢可从详情进入。
- 本次不改变买卖点计算、日期、确认状态和原有显示范围。

## 三、API 与实现边界

保持图表路径和 v26 结构引擎不变，在独立响应展示层增加：

```text
structure.display_centers:
  revision_id
  display_role: active | constituent
  parent_revision_ids

structure.display_center_levels
```

- `structure.centers` 继续只表示活动中枢；展示清单引用 `center_revisions` 中的真实修订，不复制或改写领域状态。
- 展示清单先基于完整活动快照构造，再按请求级别和行情分页过滤。`structure_level=0` 返回全部可展示层级，`1…8` 返回指定层级。
- `display_center_levels` 来自完整快照，包含组成中枢级别；原 `levels` 保持活动结构语义。
- 即使 `diagnostics=false`，也补齐常显中枢、买卖点精确修订、父子关系及必要笔和组件的引用闭包；上下文记录不自动成为矩形。
- 前端分别维护活动集合、常显集合和选中证据覆盖集合，避免现有 `active=false` 过滤误删组成中枢。
- 历史分页只合并同一运行的展示引用；运行变化时整体更新，不能拼接不同快照。
- 展示投影放在计算器指纹覆盖范围之外，不修改计算输入、定义版本或指纹规则，不重算结构、不迁移数据库。
- 保留工作区未提交修改；不修改标准笔、扩张算法、走势分类、行情、自选、普通绘图或历史分页手势。

- L1 升级后仍可在 L1 图层显示两个子中枢，但活动集合仍只有正式父结构。
