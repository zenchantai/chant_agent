# 统一方向性中枢与严格归属的周期内递归重构

## 一、目标与已确定原则

采用**“统一成枢规则、完整结构归属、反向确认、结构边界优先”**的模型，替换当前中枢分组与走势切分相互独立的实现。本方案是工程中的周期内简化模型，不宣称等同于原文跨周期递归。

已确认的设计取舍：
- **各级规则一致**：L1 使用笔；L2 使用已完成 L1 走势；L3 使用已完成 L2 走势，统一执行相同算法。
- **四单位同属一段**：进入单位与核心三单位必须归属同一走势过程，不能从另一已确认走势借用进入单位。
- **结构归属优先**：走势端点不能切开所属中枢；全段最高最低另存，不强制用作走势端点。
- **复杂结构不强行分类**：无法解释为盘整或趋势的区间保持待定，不进入高级递归；隔离后允许后续独立结构继续形成。
- 保留“反向独立中枢是走势结束的唯一确认条件”。隔离、缺口、数据结束都不算走势完成。

## 二、所有级别共用一个中枢构造器

统一输入为连续低级单位 `U0、U1、U2、U3…`。L1 的单位是已确认笔；更高级的单位必须是通过归属、边界和反向确认校验的已完成低级走势。

- **形成条件**：`U0` 是进入单位，`U1/U2/U3` 是核心；四者连续、方向交替、同数据区间与结构序列，不能重复消费。核心满足 `ZD=max(low1,low2,low3)`、`ZG=min(high1,high2,high3)`、`ZD+1e-9<ZG`。
- **方向条件**：方向只取 `U0`。向上进入要求 `start(U0)<ZD<end(U0)`；向下要求 `start(U0)>ZG>end(U0)`，统一使用严格比较容差。进入单位不参加核心交集，但属于成枢单位及外围包络。
- **价格口径**：笔使用真实端点区间；低级走势使用其全部源单位的真实价格包络，不把走势端点连线当成整段价格范围。
- **候选条件**：已有合格进入单位和两根核心单位时，保留 `2/3` 候选；第三根核心单位完成且条件成立后才形成中枢。因此 L2 最少需要**四个已完成 L1 走势**，不是三个。
- **延伸优先**：初始核心一旦形成便固定。后续单位与核心严格重叠时延伸原中枢，不每三段另建对象，不重新扩大或缩小 `ZD/ZG`。
- **暂时离开与返回**：离开后先保留待判定尾部；独立新中枢形成之前返回原核心，归入原中枢外围过程。仅接触边界既不构成严格延伸，也不证明新中枢独立。
- **独立新中枢**：后续完整四单位种子形成、核心与当前核心严格分离，才建立新中枢；相邻种子核心重叠时优先沿用旧核心。扫描按时间推进，同时成立时优先最早进入单位。
- **消费边界**：新种子不得复用旧中枢固定的进入和核心单位；新中枢确认后，从新进入单位开始的未锁定尾部从旧中枢移出，不能同时属于两个中枢。旧中枢离开记录可以引用新进入单位，但不重复拥有它。
- 停用 `extension_3x3`、`expansion` 作为父级成枢分支；扩张可以保留为关系描述，不能替代统一成枢条件，也不能按笔数自动升级。

## 三、中枢与走势联合定边界

采用**“中枢种子 → 活动中枢与走势工作区 → 反向确认事件 → 归属校验 → 提交正式走势”**的顺序。旧快照的走势日期不是新计算的前提，不再先任意切极值、再原样保留中枢引用。

- 首个合法中枢建立未完成走势，起点取其进入单位起点；此前没有合法结构的单位保留为未归属。后续走势可以从前一走势共享端点开始，包含到其进入单位之间的连接单位。
- 一个中枢及其延伸对应盘整候选；多个进入方向一致、核心沿同一方向严格分离的中枢归为趋势候选。中枢进入方向、核心位移方向分别检查，不能互相替代。
- 正式走势的 `center_ids` 只表示**所属中枢**：其进入、核心、已吸收延伸与外围单位必须全部包含在该走势的 `source_unit_ids` 内；同级走势不共享整段源单位。
- 反向确认中枢必须同级、同连续结构序列、已形成、进入方向相反，并与当前最后一个中枢核心严格分离。它是下一走势的组成，只通过 `confirmation_center_id` 确认前一走势，不进入前一走势的 `center_ids`。
- **结束边界**只从“最后所属中枢完整结束的端点，到反向中枢进入单位起点”之间选择：上升取最高、下降取最低的合法真实转折端点，同价取最早者。切分必须保证前后单位连续、方向成立、不拆低级单位、不切中枢。
- 全段最高最低另存为价格包络及极值字段。`confirmed_at` 是反向中枢证据可用的时间，不回填为极值日期，也不得早于任何必要输入的确认时间。
- 未完成走势保留真实已消费尾部，方向不随尾部回撤改变；候选端点另存。没有合法候选端点时留空，不用中枢内部极值制造正式结束。
- 若出现混合中枢关系或无合法切分边界，将此前工作区标为 `status=provisional、state=undetermined、classification=null`，清空完成证据；不能继续默认称作盘整。
- **隔离规则**：以触发冲突的新中枢进入单位起点为界，前缀封存为未完成待定区间，新中枢从自己的进入单位开始新结构序列。使用稳定的断点标识，后续高级递归不得跨越该区间；序列隔离不是走势结束确认。
- 所有级别递归重复上述过程，最高 L8。在底层已确认输入不变的前提下，追加数据不得修改已经提交的正式走势和固定核心。

## 五、验证与验收

- **统一规则测试**：同一输入形态分别作为笔和已完成走势时，产生一致的进入、核心、延伸结果；覆盖无进入单位、单点接触、四单位方向不交替、低级单位未完成。
- **归属不变量**：所属中枢的全部拥有单位必须是所属走势源单位的子集；确认中枢不属于前一走势；源单位唯一归属；任何正式中枢不得跨已确认走势边界。
- **边界测试**：全段极值位于中枢内部时不能在那里结束；合法连接区间取方向极值；无合法边界时保持待定；同价取最早合法端点。
- **延伸与隔离测试**：重叠后续单位不另建中枢，离开后返回不伪造结束；混合关系隔离后继续计算，但父级不能跨待定区间拼接。底层输入不变时验证逐前缀计算稳定性。
- **上证日线回归**：保存真实行情与输入结构证据，验证所讨论的重叠 L2 不因三段分组而重复生成；最终起点、方向由统一规则计算，不硬编码旧编号。
- **科创50回归**：验证 #41 与 #42/#43/#44 不能分别归前后走势、却仍将其组成中枢挂在前一走势。允许新规则调整旧走势端点，不预设必须删除或保留旧 #6。
- 在计算出口、入库前、独立审计中执行同一套不变量；运行后端测试、前端测试、生产构建、数据库完整性与全矩阵 API 审计，并用真实 K 线完成点击、筛选、候选线型和归属高亮的浏览器验收。
- **验收以证据和一致性为准，不以结构数量为准**：高级中枢减少、旧走势日期变化可以接受；跨归属成枢、切开中枢取端点、待定结构进入递归不可接受。交付分别报告计划保存路径、完成与未验证项目、实际检查及计划差异。
