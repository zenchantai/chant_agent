# 缠论分析工作台迭代 3：视觉层级与研究工作流重构

## Summary

目标是将当前“功能集合型行情页面”重构为一条清晰的研究路径：

`选股票 → 选周期 → 看行情 → 看缠论结构 → 查看证据 → 形成判断`

保留暗色专业盘面作为默认主题，同时完善亮色主题、移动端、布局持久化、数据同步状态和结构证据展示。

执行阶段开始后，必须先将本计划完整写入该文件并回读校验，再修改业务代码。

## Implementation Changes

### 1. 建立统一视觉设计令牌

修改 `chant_agent/web/src/styles.css`：

- 将背景、面板、边框、文字、操作色、涨跌色、结构色整理为统一 CSS variables。
- 暗色主题保持默认，降低蓝灰色占比，增加结构分析所需的金色、青色、紫色语义色。
- 亮色主题改为低饱和研究桌面风格，避免大面积冷蓝。
- 明确颜色语义：
  - 红色：上涨
  - 绿色：下跌
  - 蓝色：当前选择与可操作控件
  - 黄色：日线或核心结构
  - 橙色：数据缺口与警告
  - 红色边框：错误状态
- 统一按钮、输入框、下拉框、面板标题、状态标签和焦点态。
- 保持全局 `letter-spacing: 0`，补充 `font-variant-numeric: tabular-nums`。

### 2. 重构三栏工作台布局

修改 `chant_agent/web/src/App.tsx` 和 `styles.css`：

- 左侧自选栏默认宽度调整为约 `240px`。
- 右侧详情栏默认宽度调整为约 `320px`。
- 中间区域使用明确的内容层级：
  - 顶部工具栏
  - 行情摘要
  - 主图
  - 可折叠副图
  - 结构检查器
- 主图默认占图表区域约 `60%~65%`。
- 成交量和 MACD 副图各占约 `15%~20%`。
- 副图支持独立折叠，不再仅通过绝对百分比定位。
- 保留现有拖拽调整图表高度能力，并将高度与副图展开状态按股票、周期分别持久化。
- 增加“研究布局”预设：
  - 主图模式
  - 主图 + 成交量
  - 主图 + 成交量 + MACD
- 布局预设使用 `localStorage` 保存，不新增服务端存储依赖。

### 3. 优化顶部工具栏

调整当前 toolbar 结构：

- 分为“行情信息”“周期选择”“分析工具”“同步状态”四组。
- 股票名称、代码和市场状态保持在左侧。
- 周期控件保留分时、日线、周线、月线、5 分钟、30 分钟和更多周期。
- “画图”和“同步行情”放入分析工具组。
- 同步按钮显示状态：
  - `待同步`
  - `同步中`
  - `已同步 · 时间`
  - `部分失败`
  - `同步失败`
- 继续使用现有 `/api/stock-pool/{symbol}/sync` 和 `Stock.sync_status`、`Stock.last_sync` 字段，不新增同步 API。
- 同步失败时在按钮附近显示简短原因，详细内容进入右侧检查器。

### 4. 重做行情摘要区域

调整 `.quote` 和行情渲染：

- 主价格使用最大字号。
- 涨跌额和涨跌幅放在主价格旁边。
- 日期与市场状态使用弱化文字。
- 最高、最低、成交量、成交额、振幅使用固定列或可横向滚动的指标行。
- 桌面端避免七列等宽导致的拥挤。
- 移动端只保留最重要字段，并允许横向滑动查看完整指标。
- 缺少数据时统一显示 `--`，不留空白。
- 保持现有 `formatPrice`、`formatVolume` 和 `formatCompactNumber` 逻辑不变。

### 5. 重构缠论结构视觉编码

修改图表配置与 `structureColors.ts`：

- 普通笔使用细线和中等透明度。
- 特殊笔使用不同线型或辅助标记。
- 笔中枢使用低透明度填充和清晰边框。
- 当前选中的笔或中枢使用高亮边框、端点和轻微光晕。
- 未选中结构降低透明度，避免所有结构同等抢夺注意力。
- 不同周期使用同一套语义色的明度变化。
- 不改变结构计算结果，只改变 ECharts 展示样式。
- 保留现有 `periodStructureColor` 的周期映射和测试契约，必要时扩展为结构类型样式映射。

### 6. 将右侧栏改造成结构检查器

调整右侧栏结构：

- 顶部显示当前选中对象：
  - 类型
  - 序号
  - 方向
  - 起止日期
  - 起止价格
- 未选中结构时显示紧凑空状态，不占用过多纵向空间。
- “周期结构快照”改为摘要信息，减少版本字段的视觉权重。
- “证据检查器”作为主要内容，优先展示 `Node.evidence`。
- 证据按照“规则编号 / 解释 / 当前结构对应字段”组织。
- Agent 追问改为底部折叠区域或次级 Tab，避免和证据争夺首屏空间。
- 继续使用现有 `Node`、`evidence`、`definition_version`、`structure_version` 字段，不修改结构计算协议。
- 右侧栏支持独立展开、折叠和移动端抽屉展示。

### 7. 优化自选列表

调整左侧 watchlist：

- 分组标题显示名称、数量和当前同步状态。
- 股票行统一展示：
  - 股票名称
  - 股票代码
  - 最新价
  - 涨跌幅
  - 同步状态
- 当前股票增加明确选中背景和左侧标记。
- 删除、分组管理等次级操作继续使用图标按钮，仅在 hover/focus 时显示。
- 搜索结果显示市场、代码、名称和是否已加入。
- 保留现有分组、排序、多分组归属和拖拽能力。
- 补充空分组、搜索无结果、同步失败等状态的视觉规范。

### 8. 移动端重新设计

修改 `@media(max-width:760px)` 相关布局：

- 主页面采用单列结构。
- 左侧自选和右侧结构检查器改为抽屉。
- 抽屉打开时显示遮罩层，点击遮罩关闭。
- 顶部固定股票身份和周期控件。
- 主图优先展示，副图默认折叠。
- 右侧结构检查器在移动端从底部或右侧抽屉打开。
- 画图工具支持横向滚动和触摸操作。
- 所有触摸控件最小点击区域保持约 `32px~40px`。
- 保证股票名称、价格、按钮和指标不发生文字覆盖或横向溢出。

### 9. TypeScript 类型与接口

预计只做前端类型扩展，不改变后端公共 API：

- 新增布局状态类型，例如：
  - `ChartLayoutPreset`
  - `PanelVisibility`
  - `SubplotVisibility`
- 扩展本地布局状态的序列化结构。
- 为同步展示增加前端派生状态类型，不改变后端 `Stock` 和 `Coverage` 的现有字段。
- 若实现中发现右侧证据需要后端缺少字段，优先复用现有 `Node` 字段；只有确认无法表达时才新增可选字段，并同步补充 FastAPI 响应测试。
