# 腾讯行情风格主页面改版

计划文档目标路径：

## 总结

以腾讯股票行情页为参考，重新设计主行情工作区。默认采用浅色行情风，同时保留深色主题切换；强化行情摘要、K线信息、MA5/10/20、成交量、MACD和缩放导航，但不引入新闻、排行、盘口等扩展功能。

保留现有左侧自选、右侧缠论详情、周期顺序、画图工具、笔和中枢能力。

## 页面与图表调整

- 顶部改为紧凑证券行情头：名称、代码、交易状态、最新价、涨跌额、涨跌幅；下一行展示昨收、今开、最高、最低、成交量、成交额和振幅。
- 后端 `ChartData` 增加统一 `quote` 对象，所有周期均使用最近交易日行情作为证券摘要，避免周线、月线切换后顶部被周期K线替代。
- 行情状态使用交易日历和 `Asia/Shanghai` 时间判断：`交易中`、`午间休市`、`已休市`、`数据延迟`；保留最后更新时间。
- 周期栏继续使用：分时、日线、周线、月线、5分钟、30分钟、更多；不新增五日、1年、3年、5年快捷入口。

- K线采用A股标准样式：上涨空心红柱、下跌实心绿柱，细化影线、价格网格和主副图边界。
- 主图增加 `MA5 / MA10 / MA20`，使用固定且高对比的三种颜色；图表顶部显示当前十字光标所在K线的均线值。
- K线信息条随十字光标更新，离开图表恢复最后一根：`2026-07-29 周三`、开盘、最高、最低、收盘、涨跌额、涨跌幅、成交量、成交额。
- 后端基于完整周期数据计算 MA5/10/20，再按当前分页返回，确保分页左边界均线正确；`indicators` 增加结构化 `ma` 数据。
- 分时继续使用价格线、均价线、昨收线及昨收对称坐标；右轴增加涨跌幅，时间轴明确显示午间断点。
- 副图顺序统一为成交量在上、MACD在下；保留现有指标选择能力，但不增加 RSI、KDJ、BOLL 等指标。
- 成交量柱与对应K线同色；MACD保持红绿柱、DIF和DEA两线。
- 强化底部缩放导航条，显示淡化的价格走势预览、可拖动窗口和当前可视范围，不增加独立历史区间按钮。
- 笔、中枢和用户绘图继续覆盖在K线之上；MA线层级低于缠论结构，避免遮盖分析结果。

## 视觉与响应式

- 默认主题改为浅色行情风：浅蓝灰画布、蓝灰网格、红涨绿跌、蓝/橙/品红均线；主题按钮仍可切换现有深色模式。
- 页面保持工具型、紧凑布局，不增加装饰卡片；行情头、周期栏和图表形成连续工作区。
- 桌面端保持左右栏可折叠；移动端行情摘要压缩为最新价、涨跌幅及一行关键字段，详细字段允许横向滚动。
- tooltip、均线图例、笔中枢按钮和副图标题不得互相遮挡；图表高度调整与全屏模式继续兼容。

## 接口与类型

- `/api/chart-data/{symbol}` 增加：
  - `quote.trade_date`
  - `quote.latest`
  - `quote.change`
  - `quote.change_pct`
  - `quote.previous_close`
  - `quote.open/high/low`
  - `quote.volume/amount`
  - `quote.amplitude_pct`
  - `quote.market_status`
  - `indicators.ma[]`，每项包含 `trade_date/ma5/ma10/ma20`
- 保留现有 `bars`、`indicators.macd`、结构、绘图和分页字段，前端兼容字段缺失时的旧响应。
- 日期星期由前端按交易日期格式化为中文 `周一` 至 `周日`，不单独存储。

## 测试与验收

- 后端测试覆盖行情摘要计算、涨跌额/涨跌幅/振幅、上一交易日取值、交易状态及跨分页MA连续性。
- 前端测试覆盖中文星期、行情格式、空心红/实心绿K线配置、MA图例、十字光标信息切换和旧接口降级。
- 运行 `pytest`、`npm test`、`npm run build`。
- 启动实际服务后，用有完整日线和分时数据的指数验证分时、日线、周线、月线及分钟周期。
- 使用浏览器截图检查桌面与移动端、浅色与深色主题；确认画布非空、K线和MA可见、信息无重叠、缩放和十字光标正常。
- 与腾讯页面并排验收：信息层次、K线配色、星期日期、均线、量价副图和导航条达到同类行情页面的清晰度，但页面功能数量明显更少。

## 假设与限制

- “重新设计页面”限定为主行情工作区，不重做股票池和缠论详情业务。
- 默认浅色，保留深色主题，不固定为单一主题。
- 只新增 MA5/10/20，不新增其他技术指标。
- 不实现五日分时、盘口、逐笔成交、市场概况、热门排行、新闻和社区。
- 计划确认进入执行阶段后，先完整保存并回读本计划，再修改业务代码。
