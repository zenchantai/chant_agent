# 将笔规则切换为标准笔

## Summary

删除当前“严格笔”的运行口径，改用更接近原文实际操作流程的“标准笔”作为唯一正式规则：

```text
先处理包含关系
→ 识别严格顶底分型
→ 同类分型保留更极端者
→ 顶底交替且满足独立K线条件后成笔
```

不再要求：

```text
底分型最低点必须低于前一顶分型三K线最低点
顶分型最高点必须高于前一底分型三K线最高点
```

因此，2024-10-08 至 2025-01-13 的上证A股指数区间将按中间波段重新划分多笔，而不是压缩成一笔。

## Implementation Changes

- 修改 `app/engine.py` 的 `build_pens()`：
  - 保留包含处理、严格分型和同类分型极值筛选。
  - 保留顶底分型不能共享处理后 K 线、中间至少一根独立处理后 K 线。
  - 标准笔只使用相反分型、距离条件和方向有效性确认，不再使用 `top.trio_high` / `bottom.trio_low` 的双向极值穿透条件。
  - 删除或停用当前严格笔专用的价格过滤分支，避免同一套运行链路出现两种正式口径。
  - 保留次高次低笔、修正笔、跳空笔等已明确支持的特殊规则，但重新检查它们与标准笔的重复和冲突。
- 更新规则文档：
  - 将 `PEN-NEW-002` 改为标准笔定义。
  - 删除“严格笔”“双向价格分离”“双向价格完全分离”等容易误导的命名。
  - 明确记录：顶底价格需要有基本方向区分，但不要求双方三 K 区间做双向极值穿透。
- 结构链路全部跟随标准笔重算：
  - 笔
  - L1 中枢
  - 线段/走势相关结构
  - 买卖点候选
  - 已持久化的结构快照
- 删除严格笔模式相关的 API、前端切换项、缓存版本和测试分支，避免用户继续看到旧口径结果。
- 提升结构定义版本号，使历史严格笔快照自动失效并重新计算。

## Test Plan

- 对 `1A0002` 日线验证：
  - `2024-10-08` 后的 `2024-10-16` 底分型能够成为后续笔端点。
  - `2024-10-08` 至 `2025-01-13` 不再只生成一笔。
  - 同类顶底分型的更极端保留逻辑不变。
- 验证顶底分型之间没有独立 K 线时仍不能成笔。
- 验证包含关系处理前后，分型和笔结果一致且不重复。
- 验证中枢、结构信号与新的笔端点同步更新，不再使用旧严格笔结果。
- 验证历史严格笔结构快照因定义版本变化而重新生成。
- 保持 BaoStock 行情、股票池、同步任务、指标和现有 API 测试通过。
- 增加标准笔与旧严格笔的对照回归样例，确保旧规则不会残留在正式计算链路中。

## Assumptions

- “标准笔”定义采用当前已确认的原文流程：同类分型去弱、顶底交替、独立 K 线和基本顶底方向区分。
- 严格笔不再作为用户可选模式，也不再参与正式结构计算。
- 不删除数据库中的历史行情，只使旧严格笔结构快照失效并重新计算。
