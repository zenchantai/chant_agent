# 主图时间轴与副图坐标轴布局优化

## 摘要

在现有 `chant_agent` 前端图表基础上，解决主图与副图之间、多个副图之间 Y 轴刻度标签重叠的问题，并将时间轴从最底部移动到主图下方。

最终目标布局：

```text
主图
主图时间轴
副图 1
副图 2
副图 3
底部缩放条
```

## 坐标轴与面板布局

- 主图保留完整价格 Y 轴刻度，继续作为主要价格参考。
- 副图统一减少 Y 轴刻度密度，默认控制为约 3 个主要刻度：成交量和成交额显示顶部、中部、底部；MACD 显示 `50 / 0 / -50` 或根据实际范围生成不超过 3 个主要刻度。
- 隐藏副图最顶部的 Y 轴标签，避免与上方主图或副图的底部标签贴合。
- 副图 Y 轴标签使用略小字号和更紧凑的间距，但不改变数值精度和指标含义。
- 面板间距从当前约 `8px` 调整为约 `12px`，并为主图时间轴预留独立高度，避免时间标签与副图标签重叠。
- 保留现有主副图比例、最小高度、分隔条拖动和按股票/周期保存的布局比例。
- 当副图数量为 1～4 个、窗口为桌面或窄屏时，保证面板网格连续、无重叠、无异常空白。
- 空数据、指标关闭和分时图继续使用现有可恢复布局；分时图不套用 K 线专用的 120 根显示规则。

## 时间轴位置与缩放行为

- 只在主图下方显示时间轴标签，时间轴属于主图的底部区域。
- 副图不再显示时间轴标签，避免最后一个副图底部标签与前方坐标内容混杂。
- 时间轴与所有面板继续共享同一组 X 轴数据和 `dataZoom`：左右拖动、滚轮缩放和底部缩放条保持同步。
- 时间轴显示位置固定在主图底部与第一个副图之前；第一个副图从时间轴和避让间距之后开始布局。
- 底部缩放条继续放在最后一个副图下方，不移动到主图时间轴位置。
- 时间轴显示日期格式沿用当前格式化逻辑；根据可用宽度自动减少标签数量，避免日期文本互相覆盖。
- 主图时间轴和副图顶部之间保留足够的垂直间隔，避免日期标签与副图 Y 轴顶部标签重叠。

## 假设与默认值

- “时间轴放在主图下方”解释为时间标签紧接主图底部、位于第一个副图之前，而不是放在图表整体顶部。
- 只保留一条共享时间轴，不为每个副图重复显示日期。
- 副图默认采用稀疏刻度和隐藏顶部标签的组合方案；若仍有碰撞，优先减少标签而不是继续扩大面板间距。
- 最高价/最低价动态标记仍属于主图内容，继续随当前 `dataZoom` 可视范围更新，不移动到时间轴区域。
