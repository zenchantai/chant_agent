# 重新定义标准笔成笔规则

计划文档目标路径：`docs/plans/2026-09-15-redesign-standard-pen-rules.md`

## Summary

在保留现有包含处理、严格顶底分型、最小跨度、次高/次低特殊笔和跳空笔规则的前提下，收紧普通标准笔的成笔条件：

- 保留当前标准笔的基本方向判断；
- 新增“起点分型右侧确认 K 线的方向性反向极值必须被终点分型突破”；
- 未突破的候选不成普通笔，继续寻找后续同方向分型；
- 特殊次高/次低笔仅在普通标准笔因跨度不足或普通端点条件不成立时继续作为独立例外；
- 通过诊断信息记录被反向极值拒绝的候选，避免只能从最终笔结果反推原因。

目标是同时满足：

- 30 分钟标准笔 #25：`2026-09-03 15:00 → 2026-09-04 13:30` 不再直接确认成普通标准向上笔，因为 `3967.90 < 3980.20`；
- 日线标准笔 #185：`2024-10-08 → 2024-10-16` 仍然成笔；
- 不使用“比较两个分型三根 K 线全部整体极值”的过严规则。

## Key Changes

### 1. 重构普通标准笔判定

修改 `chant_agent/app/engine.py` 的普通笔验证逻辑：

- 保留相反严格分型条件；
- 保留处理后分型中间索引距离 `>= 4`；
- 保留顶、底分型中间 K 线的基本方向关系；
- 向上笔额外要求：
  - 起点为底分型；
  - 终点顶分型中间 K 线的 `high` 严格高于起点底分型右侧确认 K 线的 `high`；
- 向下笔额外要求：
  - 起点为顶分型；
  - 终点底分型中间 K 线的 `low` 严格低于起点顶分型右侧确认 K 线的 `low`；
- 不把起止两个分型三根 K 线的全部 `high/low` 做机械式整体区间比较；
- 不能满足新增条件的候选不标记为 `standard`。

### 2. 调整端点扫描和尾部修正

修改 `build_pens()` 及相关端点修正流程：

- 当当前反向分型不能突破起点右侧反向极值时，拒绝当前候选；
- 保留原起点，继续扫描后续反向分型；
- 后续出现更高顶或更低底时，继续按同类极值替换规则处理；
- 保持稳定前缀不可被未来数据改写；
- 让 `_repair_previous_endpoint()` 使用新的普通笔判定，避免修正逻辑重新引入被拒绝的次高/次低端点；
- 保证相邻正式笔仍然共享端点，不产生重叠或断裂。

### 3. 保留并明确特殊笔优先级

不重写特殊笔和跳空笔的业务定义，但明确判定顺序：

1. 尝试新的普通标准笔；
2. 普通标准笔不成立时，尝试次高/次低特殊笔；
3. 特殊笔仍需满足：
   - 先出现的实际极值与起点之间满足四根处理后 K 线条件；
   - 后续端点确实是较弱的次高或次低；
   - 回撤或反弹不超过前一波幅的 50%；
4. 跳空笔规则保持现有周期和指数/个股阈值；
5. 日线及以上不因普通缺口直接成笔。

特殊笔仍输出 `kind="secondary"`，普通笔仍输出 `kind="standard"`，不新增结构类型。

### 4. 增加可审计诊断

在不破坏现有 `pens` 主输出兼容性的前提下，为结构计算增加候选拒绝诊断，至少包含：

- 起点分型索引、日期和价格；
- 起点右侧确认 K 线索引、日期及其方向性极值；
- 候选终点分型索引、日期和价格；
- 候选终点对应方向极值；
- 拒绝原因，例如：
  - `reverse_extreme_not_broken`
  - `insufficient_distance`
  - `same_kind_fractal`
  - `secondary_rule_not_satisfied`
- 诊断只记录候选和判定依据，不把被拒绝候选写入正式 `period_pens`；
- 前端优先复用现有结构诊断面板或结构详情接口，不改变正式笔对象字段语义。

### 5. 更新规则和版本指纹

同步更新：

- `chant_agent/knowledge/chan_rules.yaml`
  - 把 `PEN-NEW-002` 改为新的方向性反向极值规则；
  - 明确“不比较两组三 K 线整体极值”；
  - 明确普通笔失败后继续寻找后续候选；
  - 保留 `PEN-SPECIAL-001` 的特殊笔例外语义。
- `chant_agent/knowledge/chan_rules.md`
  - 增加规则解释、公式、30 分钟 #25 和日线 #185 对照案例。
- `chant_agent/app/rules.py`
  - 更新定义版本；
  - 保证快照指纹变化后旧结构不会被误认为仍匹配当前算法。

## Recalculation and Compatibility

规则实现并通过单元测试后，全量重算当前启用股票池：

```text
1A0001、1A0688
×
5、30、d、w、m
```

重算要求：

- 先保留当前数据库、WAL、SHM 文件；
- 不删除历史行情、分型、手动画线和非目标结构数据；
- 重新生成 `period_pens`、笔中枢、层级中枢、走势及相关快照；
- 更新 `calculator_fingerprint`；
- 验证旧快照不会继续被错误复用；
- 不改变现有 API 的股票、周期和返回字段兼容性；
- 保留工作区当前与本任务无关的未提交修改，不回滚、不覆盖。

## Test Plan

### 单元测试

在 `chant_agent/tests/test_engine.py` 增加：

- 向上笔必须突破起点底分型右侧 `high`；
- 向下笔必须跌破起点顶分型右侧 `low`；
- 30 分钟 #25 型案例：
  - 候选顶 `3967.90`；
  - 起点右侧反向高点 `3980.20`；
  - 普通标准笔被拒绝；
- 日线 #185 型案例：
  - `2024-10-08 → 2024-10-16`；
  - 新规则仍形成标准向下笔；
- 候选被拒绝后继续寻找后续顶/底分型；
- 后续更高顶或更低底能够正确替换临时端点；
- 普通笔失败后，满足条件的次高/次低特殊笔仍可成立；
- 不满足 50% 回撤限制的特殊笔仍被拒绝；
- 索引距离为 3 的候选仍不能成为普通标准笔；
- 包含处理、跳空笔、同类分型去弱和既有尾部修正测试继续通过。

## Assumptions

- 采用“方向极值”方案：
  - 向上只要求终点顶 `high` 突破起点底右侧 `high`；
  - 向下只要求终点底 `low` 跌破起点顶右侧 `low`。
- 不采用比较两组三 K 线全部整体极值的方案，因为该方案会错误否定日线 #185。
- 特殊次高/次低和跳空笔暂不重新定义，只收紧普通标准笔。
- 普通笔候选失败后继续寻找后续分型，不把失败候选标记为正式 `provisional` 笔。
- 计划阶段只做只读核查；用户确认并进入执行阶段后，第一步先将本计划完整保存到：
  `docs/plans/2026-09-15-redesign-standard-pen-rules.md`
- 保存计划后立即回读核验，再开始修改业务代码。
