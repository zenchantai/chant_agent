# K线普通图形颜色与样式编辑方案

## 总结

为普通绘图对象增加完整样式编辑能力：线段、直线、矩形均可修改颜色、线宽和线型；矩形边框、填充颜色与透明度独立可调。样式随图形保存，刷新、分页、缩放、切换周期后保持。系统自动生成的笔和 L1 中枢继续使用固定周期颜色，不开放样式覆盖；普通绘图不参与笔、中枢和 Agent 计算。

## 前端交互

### 样式面板

在画图模式下选中普通图形后，右侧显示“图形样式”面板：

- 颜色：原生颜色选择器和十六进制输入框。
- 线宽：`1px / 2px / 3px / 4px / 6px`，允许数字输入，范围限制为 `1–10px`。
- 线型：`实线 / 虚线 / 点线`。
- 矩形额外显示填充颜色、填充透明度 `0–100%` 和“无填充”。
- 线段、直线不显示填充选项。
- 修改立即更新图表，但只进入本地草稿。
- 提供“恢复默认样式”。

默认样式：普通线段/直线使用当前周期主题色变体、`1.5px`、实线、透明度 `0.9`；矩形使用相同边框样式，填充透明度暗色 `14%`、亮色 `10%`。

颜色只接受 `#RRGGBB` 或 `#RRGGBBAA`；非法颜色恢复上一次有效值并提示；透明度统一保存为 `0–1`；线宽拒绝负数、零和超过上限的值。

### 实时预览与编辑会话

- 样式变化立即反映在图表上，选中对象显示高亮和控制点。
- 样式变化标记为未保存草稿。
- 保存、取消、撤销、重做均包含样式变化。
- 退出编辑模式且存在未保存修改时，提示“保存 / 放弃 / 继续编辑”。
- 顶部保持图标化工具栏：`选择 | 线段 | 直线 | 矩形 | 撤销 | 重做 | 保存 | 取消`。

## 数据模型、API 与校验

前端 `Drawing.style`：

```ts
type DrawingStyle = {
  color?: string;
  width?: number;
  line_type?: "solid" | "dashed" | "dotted";
  opacity?: number;
  fill_color?: string;
  fill_opacity?: number;
};
```

历史数据兼容：缺少 `line_type` 默认为 `solid`；矩形缺少 `fill_color` 时使用 `color`；缺少 `fill_opacity` 时使用主题默认值；旧矩形继续正常显示。

后端统一 `validate_drawing_style()`，由创建、单条更新和批量更新共同调用，校验颜色、线宽、线型和透明度；非矩形出现填充字段时拒绝。

保持接口：

```text
GET    /api/drawings/{symbol}?timeframe=d
POST   /api/drawings/{symbol}
PATCH  /api/drawings/{symbol}/{drawing_id}
POST   /api/drawings/{symbol}/batch
DELETE /api/drawings/{symbol}/{drawing_id}
```

批量请求包含 `timeframe`、`base_version`、`create`、`update` 和 `delete_ids`。服务端先完整校验，再在单事务内保存；任一项失败或版本冲突则整批回滚，并返回最新绘图列表及 `drawings_version`。数据库继续使用 `drawing_objects.style` JSON 字段，不做破坏性迁移。

## 图表渲染

新增统一 `normalizeDrawingStyle()`，将 `Drawing.style` 转换为 ECharts `lineStyle`/`areaStyle`：

- `solid`、`dashed`、`dotted` 映射为对应 `lineType`。
- `width` 映射线宽，`opacity` 映射线条透明度。
- 矩形边框使用自定义颜色、宽度、线型和透明度，填充使用 `fill_color` 与 `fill_opacity`。
- 动态预览和选中控制点使用对象当前样式。
- 系统笔和 L1 中枢仍使用周期主题色，不读取普通绘图样式。

普通图形默认颜色由统一的 `timeframe + theme` 函数生成；用户修改后的颜色保存在对象本身，不因主题切换覆盖。

## 撤销、重做与保存

- 改颜色、线宽、线型、填充颜色或透明度均记录编辑命令。
- 连续拖动颜色输入或透明度滑块时节流，并在松开后合并为一个撤销步骤。
- `Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Shift+Z` 重做。
- 保存成功后清空草稿历史；取消恢复进入编辑模式前的完整样式快照。
- 保存期间锁定相关按钮，防止重复提交。

## 范围边界

- 系统自动生成的笔颜色、线宽、线型不允许修改。
- 系统 L1 中枢边框和填充不允许修改。
- 不增加渐变、阴影、箭头、纹理等高级样式。
- 不把普通图形转换为系统笔或中枢。
- 不改变缠论结构版本和算法。
- 移动端首版仅浏览，不支持样式编辑。

## 测试与验收

后端覆盖合法/非法颜色、线宽、线型、透明度、矩形填充、非矩形填充拒绝、单条/批量校验、事务回滚、版本冲突和历史字段兼容。前端覆盖三类图形样式实时预览、虚线/点线渲染、矩形填充透明度、撤销/重做、保存刷新、取消恢复、主题与周期隔离，以及移动端无横向溢出。

验证命令：

```bash
uv run --with-requirements requirements.txt --with pytest python -m pytest -q
cd web && npm test
npm run build
```

桌面验收重点确认颜色修改立即预览、线宽和线型清晰、矩形填充不遮挡 K 线、保存/取消/撤销/重做一致，以及刷新后样式正确恢复。

## 默认假设

- “所有图形”按已确认选择解释为所有普通绘图对象；系统笔和中枢继续固定周期配色。
- 普通图形颜色默认跟随创建时的周期主题色，用户修改后不再随主题自动改变。
- 矩形边框和填充颜色独立保存。
- 样式编辑采用编辑会话统一保存，不新增即时单条保存按钮。
- 普通绘图不进入缠论结构哈希、结构计算或 Agent 证据。
