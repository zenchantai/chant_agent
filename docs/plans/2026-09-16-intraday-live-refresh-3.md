# chant_agent 分时图盘中实时刷新

## 一、目标与计划保存

打开股票分时图时主动获取最新分时数据；交易时段内每 **15 秒**自动刷新，午休及收盘补取一次后暂停，下一交易时段自动恢复。

## 二、刷新行为

- **首次打开、切换股票或切回分时图**：先显示已有缓存，再主动获取最新数据；没有缓存时显示加载状态。
- **交易时段**：采用 `Asia/Shanghai` 时区和交易日历，刷新窗口设为 `09:30–11:30`、`13:00–15:00`，包含收盘集合竞价，不包含开盘集合竞价与盘后交易。该窗口覆盖交易所规定的连续竞价及收盘集合竞价时段。([sse.com.cn](https://www.sse.com.cn/lawandrules/sselawsrules2025/fund/trading/c/c_20260424_10817739.shtml?utm_source=openai))
- **持续停留**：每 15 秒发起刷新；已有请求未完成时不叠加请求。这里只承诺定时拉取数据源最新的一分钟粒度数据，不承诺逐笔或秒级行情。
- **休市处理**：休市时打开补取一次最近可用交易日数据；跨入午休、收盘后延迟 15 秒补取一次，随后停止行情轮询。到下一开盘时点立即恢复。
- **页面可见性**：页面隐藏、切到其他周期或组件卸载时停止轮询并取消请求；重新可见时补取一次，再按市场状态调度。
- **失败处理**：保留上次有效图表，提示刷新失败和数据时间；盘中下一轮重试，休市不持续重试。昨日数据必须明确标注日期，不得伪装成今日实时数据。

## 三、实现与接口

### 后端：轻量实时获取

- 扩展现有 `GET /api/chart-data/{symbol}`，新增 `refresh=false` 参数。仅允许 `timeframe=1` 且未指定 `before` 时使用 `refresh=true`；其他刷新组合返回 `400`，原有普通读取保持兼容。
- 新增独立分时刷新服务，复用现有腾讯 `m1` 解析能力，不调用股票池全量同步，不触发其他周期更新或缠论结构重算。
- 按股票、周期、复权标识合并并发请求；15 秒内复用最近一次尝试结果，包括失败结果，避免多页面重复请求。与既有分时同步共享写入保护，防止晚返回的旧快照覆盖新数据。
- 从返回数据中选择最新可用交易日期，排序、去重、验证后保存。分时数据始终只保留一个交易日；旧日期响应、空数据及无效数据不得清空或覆盖更新的缓存。跨日替换在同一事务内完成。
- 分时图走轻量组装分支，计算原有指标并读取绘图配置，保持缠论结构数组为空，不依赖实时行情对应的新结构快照。
- 分时顶部报价与图线使用同一交易日数据，避免继续优先展示旧日线报价。昨收只采用可确认的对应前一交易日数据；昨收或成交额不可用时显示 `--`，不拿当日开盘价或零值冒充。
- 为分时响应新增 `intraday_refresh` 元数据：服务器时间、市场阶段、下次阶段切换时间、数据日期、最新数据时间、最近获取成功时间、获取结果及错误提示。区分“请求成功”和“今日行情已更新”。
- 交易日历优先读取本地明确记录；缺失时按需补查。查询失败标记“交易日历未知”，不直接当作休市或用工作日猜测；允许打开时获取一次，之后每 60 秒重试日历，确认交易阶段后恢复正常调度。

### 前端：静默更新与状态保留

- 独立封装分时刷新调度，使用后端时间和阶段信息决定轮询及休市唤醒；复用请求取消及股票/周期身份校验，防止快速切换时串图。
- 自动刷新只更新行情、指标、报价和刷新状态，不走会清空编辑状态的完整加载流程。
- 保留副图数量与类型、面板高度、缩放范围、十字光标位置和未保存绘图；首次加载保持原有默认分时视图。
- 展示“交易中／午间休市／已休市／日历未知”、数据日期和最新数据时间；刷新失败使用非阻塞提示，不反复弹窗或使图表闪烁。

## 四、测试、验收与边界

- **后端测试**：覆盖开盘、午休、下午恢复、收盘、周末、节假日及日历缺失；使用固定时间和模拟行情，不依赖真实市场开盘。
- **数据测试**：覆盖昨日缓存切今日、最近交易日回退、同一分钟更新、乱序重复、旧响应晚到、空响应、超时和并发刷新；验证失败不删缓存、跨日不混线、不修改其他周期。
- **接口测试**：验证旧调用兼容、新参数限制、刷新元数据、同日报价和缺失值处理；验证实时分支不生成额外结构快照。
- **前端测试**：使用假时钟验证 15 秒轮询、请求不重叠、休市补取、隐藏暂停、可见恢复和切股竞态；检查刷新不清空图表设置及编辑状态。
- **执行检查**：运行后端 `pytest`、前端 `npm test` 和 `npm run build`。重启受影响的本地服务后，核对监听进程、延迟健康检查及实际分时接口；浏览器验证图线、报价、时间标签和设置保留。
- **验收限制**：若实施时不在交易时段，真实盘中持续更新标记为“未验证”；模拟测试、接口成功和构建通过不能替代盘中浏览器验收。
- **默认范围**：仅当前打开的分时图按需刷新，不批量刷新整个自选池，不增加付费数据源，不改其他 K 线周期、缠论规则或既有晚间同步安排。
- **执行交付**：分别报告实际计划文件绝对路径、已完成内容、未完成或未验证内容、实际测试与运行检查，以及偏离原计划之处；实质变更须先保存新的完整计划版本。
