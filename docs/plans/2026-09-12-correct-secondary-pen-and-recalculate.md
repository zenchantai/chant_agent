# 修正次高/次低特殊笔并重算全部结构

计划文档目标路径：

`/Users/saber/Desktop/saber/投资/缠论/docs/plans/2026-09-12-correct-secondary-pen-and-recalculate.md`

## Summary

依据 [8月半年课150808 第二课 笔的定义.doc](/Users/saber/Desktop/saber/投资/缠论/8月半年课150808 第二课 笔的定义.doc) 修正次高/次低特殊笔规则：

- 普通笔继续要求顶底分型中心至少相差 4 个处理后索引，即端点之间至少 5 根处理后 K 线。
- 特殊笔的“四根 K 线”改为衡量“原始最高点/最低点之间”的处理后 K 线数量。
- 不再把“当前端点到次高/次低分型”的整体窗口长度直接当作四根 K 线条件。
- `1A0001` 周线 `2023-03-10 -> 2023-03-31` 应被判定为不成特殊笔。
- 修正后的笔结果重新驱动现有方向性 L1 中枢重建。

本次保持工程现有方向性 L1 中枢定义，不重新扩展为线段、递归走势或原文完整走势中枢体系。

## Implementation Changes

### 1. 修正特殊笔判定

修改 `chant_agent/app/engine.py` 的特殊笔逻辑：

- 保留标准笔判定作为第一优先级：
  - 顶底分型交替；
  - 分型不共享处理后 K 线；
  - 中间至少一根独立处理后 K 线；
  - 顶底基本方向有效。
- 特殊笔只在标准笔因距离不足而不能成立时尝试。
- 对次高/次低特殊笔显式区分：
  - 前一端点；
  - 先出现的实际最高/最低极值；
  - 后续次高/次低分型。
- 四根 K 线条件使用“前一端点到实际最高/最低极值”的处理后 K 线跨度，不使用“前一端点到次高/次低候选端点”的总窗口长度替代。
- 四根 K 线按处理后 K 线索引计数，并采用包含端点的数量。
- 保留次高/次低相对前一极值的 50% 回撤限制：
  - 上行后次高点：次高点相对前高的回撤不得超过前一波幅的 50%；
  - 下行后次低点：次低点相对前低的反弹不得超过前一波幅的 50%。
- 要求次高/次低确实相对初始极值更弱，不能把新的更高高点或更低低点错误当成次高/次低。
- 保留现有修正笔的尾部全量重算、同类极值替换和路径修复逻辑，并检查其与新特殊笔候选的组合关系。
- 跳空笔规则保持不变：仅适用于 5/30 分钟，日线及以上不按缺口直接成笔。

针对当前问题的回归事实：

```text
1A0001 周线：
顶分型 index=308，日期 2023-03-10
第一底分型 index=309，日期 2023-03-17
次顶分型 index=310，日期 2023-03-24
次底分型 index=311，日期 2023-03-31
```

顶分型到实际最低点只有 2 根处理后 K 线，因此不能通过特殊笔的四根 K 线条件；不得再生成 `2023-03-10 -> 2023-03-31` 这条 `secondary` 笔。

### 2. 更新规则来源和版本

同步修改：

- `chant_agent/knowledge/chan_rules.md`
- `chant_agent/knowledge/chan_rules.yaml`
- `chant_agent/app/rules.py`

内容要求：

- 明确普通笔的 5 根 K 线条件；
- 明确特殊笔四根 K 线衡量的是最高点到最低点的极值跨度；
- 明确次高/次低端点只是在标准笔距离不足时的例外；
- 说明特殊笔来源为《8月半年课150808 第二课 笔的定义》，不是普通笔基础定义；
- 结构定义版本从 `chan-period-standard-pen-directional-l1-center-v8` 升级到下一版本，例如：
  `chan-period-standard-pen-directional-l1-center-v9`；
- 版本升级用于使历史 v8 结构快照失效，避免旧特殊笔结果继续被读取。

中枢规则不改定义，只保留现有工程规则：

- 进入笔 `P0`；
- 后续连续三条核心笔 `P1/P2/P3`；
- 三笔方向交替；
- `ZD=max(low(P1..P3))`；
- `ZG=min(high(P1..P3))`；
- 必须严格满足 `ZD < ZG`；
- 后续严格重合笔继续延伸现有 L1；
- 新笔结果变化后重新判断中枢边界、延伸、外围和终止。

### 3. 测试补充和调整

在 `chant_agent/tests/test_engine.py` 增加或调整：

- 普通笔中心索引差为 `3` 时不成标准笔；
- 普通笔中心索引差为 `4` 时成立；
- 特殊笔必须满足极值跨度至少 4 根处理后 K 线；
- 端点总窗口达到 4 根、但前一端点到实际极值不足 4 根时，特殊笔必须拒绝；
- 50% 回撤边界值允许，超过 50% 拒绝；
- 次高/次低方向错误时拒绝；
- 上行次高和下行次低两种方向分别覆盖；
- 当前 `1A0001` 周线样例不再生成 `2023-03-10 -> 2023-03-31`；
- 修正笔候选重算不因新规则产生路径依赖；
- 跳空笔、标准笔、包含处理和中枢现有测试继续通过。

中枢测试增加：

- 删除一条错误 `secondary` 笔后，后续笔序列重新排列；
- 中枢不会引用不存在或旧版本笔 ID；
- 中枢核心区间、延伸笔、离开笔和终止原因与新笔序列一致。

## 重算和验证

### 重算范围

每个标的重算：

```text

```

只使用数据库中已有行情，不重新拉取或改写行情数据。

### 重算流程

1. 先备份当前数据库及现有 WAL/SHM 文件。
2. 修改规则版本和引擎实现。
3. 使用 `PeriodStructureService.ensure(..., force=True)` 对全部标的和周期重建结构。
4. 通过 `replace_period_structure()` 写入新的结构运行快照并切换 active run。
5. 保留旧 v8 运行记录作为审计数据，不删除行情数据。
6. 当前数据库没有 active 手工结构覆盖；如重算前发现新增覆盖，保留覆盖记录并检查失效锚点。

### 验收检查

- 所有 active 结构版本均为 v9；
- active 结构不再引用 v8 笔或中枢；
- 所有普通笔满足至少 5 根处理后 K 线；
- 所有 `secondary` 笔满足新的极值跨度和 50% 回撤条件；
- 周线、月线没有跳空直接成笔；
- `1A0001` 周线不再存在：
  `2023-03-10 -> 2023-03-31`；
- `period_pen_centers` 中所有 `source_pen_ids`、`formation_pen_ids`、`core_pen_ids`、`extension_pen_ids`、`departure_pen_ids` 都存在于同一 active run；
- 中枢只由当前 active run 的确认笔生成；
- 结构版本、笔数量、特殊笔数量、中枢数量记录重算前后差异。

## Assumptions

- 本次“四根 K 线”按用户确认的语义执行：衡量原始最高点/最低点之间的去包含处理后 K 线跨度，而不是简单衡量次高/次低候选端点之间的总窗口。
- 中枢本身不切换为原文完整递归走势中枢，只根据修正后的笔重建现有方向性 L1 中枢。
- 不修改行情数据、不重新下载行情、不删除旧结构快照。
- 规则版本升级后，所有启用标的和全部五个周期都强制重算。
- 计划确认后，第一步先将本计划完整写入上述计划文件并立即回读校验；计划文件写入和核验成功后，才开始修改业务代码。
