# 缠论结构图形可选中交互优化

## Summary
- 在 `chant_agent` 前端为笔、中枢、线段、走势增加独立的透明命中层，扩大可点击区域，不改变现有图形的正常视觉样式。
- 点击结构后统一更新现有 `selected: Node | null` 状态，联动右侧“证据检查器”展示对应结构详情。
- 点击图表空白区域时清空当前选中状态和图形高亮。
- 计划文档保存为：`/Users/saber/Desktop/saber/投资/缠论/chant_agent/docs/plans/2026-09-14-structure-selection-interaction.md`

## Key Changes
- 扩展 `web/src/chartBuilders.ts` 的图表构建上下文，支持当前选中结构标识，并为笔、线段、中枢、走势生成透明或低透明度的可点击命中系列。
- 命中层使用明显大于实际线宽的 `lineStyle.width`，同时设置透明 `opacity`、`silent: false` 和结构 ID 元数据，确保点击事件能准确回传：
  - 笔：沿实际两点连线扩大命中范围；
  - 线段：沿线段真实边界扩大命中范围；
  - 中枢：覆盖中枢矩形区域，并支持点击中枢内部任意位置；
  - 走势：覆盖走势边界线、端点及必要的路径区域。
- 处理图层重叠时按结构语义设置稳定优先级，避免透明命中层遮挡K线、指标和手动画图；手动画图编辑模式继续优先处理已有绘图交互。
- 选中结构后对对应真实图形增加高亮表现，包括提高线宽、透明度或边框强调；取消选择后恢复默认样式。
- 扩展 `web/src/App.tsx` 的 ECharts 点击与空白点击处理：
  - 从命中层中的 `penId`、`segmentId`、`centerId`、`movementId` 解析节点；
  - 复用现有 `onSelect` 和右侧详情渲染逻辑；
  - 点击空白区域调用 `onSelect` 的清空路径；
  - 保留现有右键编辑、结构拖拽和手动画图行为。
- 如现有 `onSelect` 类型只接受非空 `Node`，调整为支持 `Node | null`，并确认切换股票、周期或刷新数据时不会残留旧结构选择。
- 右侧详情继续使用现有字段展示逻辑，不新增后端接口；必要时补充笔、线段、中枢、走势的结构类型标题和摘要信息，确保选中对象与右栏内容一一对应。
- 更新 `web/src/styles.css`，增加选中结构的视觉状态及必要的鼠标指针样式，不改变现有面板布局和可调整图表高度能力。

## Assumptions
- 沿用现有 `selected` 状态和右侧“证据检查器”，不新增后端数据模型或接口。
- “等图形”包含当前已渲染的正式走势；分时图继续遵循现有规则，不显示缠论结构时不增加结构命中层。
- 透明命中层只扩大交互范围，不改变结构的默认颜色、虚实线和层级语义。
- 不覆盖当前工作区已有未提交修改；实现仅聚焦图形选择交互，不处理无关代码或结构算法变更。
- 结构重叠时采用固定优先级并通过测试锁定，默认优先选择更具体、可直接定位的结构，再回退到面积型中枢命中。
