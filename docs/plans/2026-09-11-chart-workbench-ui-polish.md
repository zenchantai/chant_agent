# 缠论分析工作台界面优化

## 总结

统一行情数值格式，重组主图工具栏与副图控制区，精简无业务价值的技术文案，并改善侧栏、同步操作及移动端交互。保持现有后端接口、缠论算法、数据结构和用户本地配置不变。

计划文档目标路径：

`docs/plans/2026-09-11-chart-workbench-ui-polish.md`

## 实现调整

- 建立统一前端格式化函数：
  - 价格固定显示 2 位小数，覆盖自选列表、行情栏、K 线提示、价格坐标轴、绘图预览及结构价格。
  - 成交量、成交额小于 1 万显示整数；1 万至 1 亿显示四舍五入后的整数万；1 亿及以上显示 2 位小数亿。
  - 无效或缺失值统一显示 `--`。
  - K 线悬浮信息增加已有的“成交额”字段。
- 重做副图控制区：
  - 删除所有可见的“副图1”“副图2”文字和内部系列名前缀。
  - 在每个副图上方预留独立工具条带，与相邻图表形成明确间距，不再覆盖绘图区。
  - 选择器改为弱边框或透明边框样式，仅在悬停、聚焦时显示轮廓。
  - 选项显示为 `MACD(12,26,9)` 和 `成交量`。
  - 成交量副图左侧坐标轴及提示信息使用统一大数单位；MACD 保持指标精度。
- 重组主图工具栏：
  - 保留“股票名称与代码”“周期”“缠论”“画图”“同步行情”四个清晰功能组。
  - 将“笔”“中枢”开关和“显示全部”放入默认收起的“缠论”弹出菜单。
  - “笔”“中枢”继续使用复选开关并保留现有本地记忆；“显示全部”作为恢复完整缩放范围的命令。
  - 菜单支持点击外部或按 `Escape` 关闭，并提供清晰的键盘焦点状态。
- 将“更新”改为“同步行情”：
  - 保持现有接口语义，即同步当前股票的全部五个周期。
  - 请求期间禁用按钮并显示同步状态；提交成功或失败通过页面提示反馈，不再把结果隐蔽地写入右栏追问结果。
- 精简页面信息：
  - 顶部改为图标加中文标题“缠论分析工作台”，删除 `PERIOD PEN CENTER` 和 `PAPER ONLY`，右侧仅保留主题切换。
  - 删除“行情与结构周期”“行情状态”“结构来源”等常态技术文字。
  - 保留结构不可用、数据缺口、同步失败等真正需要用户处理的异常提示。
  - 图例移入“缠论”菜单或紧邻菜单展示，避免单独占用图表上方一行。
- 左右侧栏改为单击折叠或展开，更新动态 `title`、`aria-label` 和展开状态；移动端保持抽屉式侧栏，并确保按钮触控区域不小于 32px。
- 调整桌面与移动端工具栏换行、间距和图表高度分配，避免菜单、副图工具条、行情信息及侧栏按钮相互遮挡。

## 接口与兼容性

- 不修改后端 API、数据库或缠论计算逻辑。
- `POST /api/stock-pool/{symbol}/sync` 保持同步当前股票全部周期。
- 保留现有主题、侧栏状态、缠论图层、副图指标和缩放范围的 `localStorage` 数据。
- 不引入新的 UI 组件库，继续使用 React、ECharts 和现有 Lucide 图标。

## 测试与验收

- 为价格和大数格式化补充边界测试：缺失值、零、`9999`、`10000`、接近 `1亿`、等于及超过 `1亿`。
- 更新 K 线提示测试，验证价格固定两位、成交量/成交额单位以及不混入 MACD 字段。
- 运行 `npm test` 和 `npm run build`。
- 启动页面后分别检查桌面和移动端：
  - 缠论菜单展开、关闭、图层切换和“显示全部”。
  - 两个副图选择器的位置、弱边框样式和指标名称。
  - 成交量坐标轴、K 线提示及所有价格显示。
  - 同步按钮的处理中、成功和失败状态。
  - 左右侧栏单击切换、窄屏抽屉及无重叠、无横向溢出。
  - 深色和浅色主题下的对比度与焦点状态。

## 假设

- “价格只保留2位小数”适用于页面全部用户可见价格，不修改后端原始精度。
- 大数换算按绝对值判断单位并保留正负号；“整数万”采用四舍五入。
- “成交额”加入 K 线悬浮信息，但不新增独立成交额副图。
- 顶部不再显示模拟环境标识；系统仍保持 `paper_only`，不改变任何交易能力。
- 缠论菜单每次进入页面默认收起，图层选择继续按股票和周期记忆。
