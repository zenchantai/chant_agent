# 周期内笔中枢与非同级别分解规则

正式版本：`chan-period-directional-z-center-v28`。

引擎需求基线为 `docs/requirements/2026-09-18-pen-center-non-same-level-chan-engine-requirements.md`，周期策略与跨周期展示按 `docs/plans/2026-09-19-daily-weekly-monthly-linkage.md` 执行，理论语义主要来自 `../读缠论108课札记.pdf`。工程把每个行情周期的确认笔视为该周期数据域内的最低完成走势单位；日线 `L2/L3` 不映射为真实周线或月线级别。

## 计算链路

`K线 -> 包含 -> 分型 -> 确认笔 -> 走势工作区 -> 进入段 + 最早合法三单位核心 -> 中枢状态机 -> 结构买卖点 -> 走势边界 -> 完成走势递归`

5分钟、30分钟、日线使用 `calculation_profile=full`，沿用上述完整计算链路。周线、月线使用 `pen_centers_only`，只计算确认笔、L1 笔中枢及其延伸。各周期原生结构独立计算，不跨行情缺口、数据断点或序列边界。

## 周月参考与日线投影

- 周月中枢仍使用三笔固定核心、延伸、离开返回及回试状态判定；内部进入、离开和回试组件仅作为证据。状态判定不创建买卖点对象。
- 周月不计算中枢关系、扩张、升级、走势、背驰或买卖点，包括候选构件。满足完整模式扩张条件的两个中枢仍各自保留为 L1；走势、点与关系集合为空。
- 周月图中的日线 L2 是独立显示叠加，取自日线完整快照的展示目录，包含活动 L2 及升级后仍可展示的组成 L2。叠加保留日线日期、价格、家族与修订身份，不改变周月笔、中枢和原生最高级别。
- 日线正式结构及投影仅消费已收盘确认数据。既有历史数据建立一次性完成基线；当日确认绑定实际行情内容，内容改变后旧确认失效。缺少完成证明的缓存不会因时间跨过收盘或跨日自动转为正式；形成中数据只用于独立预览。
- 以下扩张、买卖点、走势与递归规则仅适用于 `full` 策略。

## 中枢

教材依据为红炉火《中枢、走势类型和买卖点》第 3、15、16、22—25 页；实施基线为 `docs/plans/2026-09-19-directional-pen-center-refactor-2.md`。

- 确认三单位上—下—上且 P2>P0、P3>P1 建立向上上下文，下—上—下对称；这是工程方向判据，非教材原文定理。边界及有效离开回试证据优先。
- 向上过程取下—上—下回调核心，向下过程取上—下—上回升核心。失败窗口只推进同方向起点，活动核心不能任意重选。
- 原点重叠结构保留方向待定修订；方向及相应核心齐备时追加规范化修订。分页不重置原点；任意截断须标为边界候选。
- 初始三单位严格连续并有正宽度交集。方向性核心 ZD/ZG 固定，等于 A/C 交集。
- Z 只含同形成方向的核心 A/C 和已接纳延伸；闭区间触边可延伸。分别维护 GG/G/D/DD，进入、外围、离开和连接不能污染 Z 指标。
- 两个合法同级核心分离，Z 闭区间接触或重叠确认扩展事件；实际见证、源连续性、连接和证据时间必须齐全。扩展事实与高级核心几何分别记录。
- 高级核心由三段次级走势真实区间交集确定。第三段可未完成并显示动态区间，不冒充完成走势递归。缺少三段边界时保留低级组成，显示扩展已成立、区间待确定，禁止用两个包络交集替代。
- 九段仅检查构成一致性，不自动升级；禁止传递重叠合并。三类点保持严格离开回试口径，扩展触边比较不得隐式改变点位规则。
- 高级修订与所有时间证据不可回写；过去结构与当前代表修订分开保存。

## 买卖点与走势

- 一类点只允许出现在至少两个同级中枢构成的趋势中。单中枢力度减弱只是盘整背驰。
- 力度优先比较内部最高中枢级别与已确认子走势数，相同时再比较振幅和按实际K线数计算的平均斜率。`MACD` 只是辅助证据；明确增强时保持候选。
- 一类点的 `point_date/point_price` 是真实极值，`confirmed_at` 是后续反向低级走势完成的证据时间。二类点依赖已确认一类点，三类点要求完整离开和第一次完整回试不进入核心。
- 走势至少完整包含一个同级中枢，边界不得切开中枢核心。相邻走势只共享一个真实价格端点，不共享整笔、组件或低级走势。
- 一个同级中枢为盘整；两个以上完整中枢系统依次严格向上或向下分离为上涨或下跌；扩张关系不判同级趋势。
- 无法唯一确认的结构保持 `candidate/provisional/undetermined/truncated`，不用数据结束或默认值伪造完成证据。

## 递归与存储

`L2` 以上只消费连续、已确认、分类明确且 `recursive_eligible=true` 的低级走势，不再直接消费笔，递归上限 `L8`。中枢、走势和结构点使用稳定 family 标识与只追加 revision 证据。正式视图默认只显示当前活动修订，历史修订和失效候选仅在诊断模式返回。
