# 各周期笔与方向性 L1 中枢规则

正式版本：`chan-period-standard-pen-right-extreme-v19`。

## 运行链路

`本周期K线 -> 包含 -> 严格分型 -> 标准笔/特殊笔 -> 方向性L1笔中枢 -> 本周期走势`

5分钟、30分钟、日线、周线和月线各自读取本周期行情、计算和保存结构。任何周期的数据变化都不会触发其他周期的结构变化。日线 L1/L2/L3 与日线/周线/月线的对应仅用于显示颜色和产品解释，不把日线走势写入周线笔，也不作为跨周期递归输入。

## 普通笔

包含和分型按《读缠论108课札记》第62、65、77课执行。笔采用标准笔：顶底交替，分型不共享处理后K线，中间至少一根独立K线，并要求顶底保持基本方向关系。有包含处理上下文时，顶分型中间K线的高低点均高于底分型中间K线；向上笔的终点顶分型中间K线 `high` 必须严格突破起点底分型右侧确认K线 `high`，向下笔的终点底分型中间K线 `low` 必须严格跌破起点顶分型右侧确认K线 `low`。不比较双方三K区间整体极值；普通候选失败后继续扫描后续分型，特殊笔仍按例外规则处理。

该方向性反向极值规则用于避免把尚未被终点消化的次高/次低端点直接画成普通标准笔。30分钟 `2026-09-03 15:00 → 2026-09-04 13:30` 候选因 `3967.90 < 3980.20` 不直接确认；日线 `2024-10-08 → 2024-10-16` 仍满足向下突破条件并成笔。

## 特殊笔

依据《8月半年课150808 第二课 笔的定义》：

- 次高/次低笔是普通五 K 线标准笔的例外，仅在标准笔不能成立时尝试。四根 K 线条件衡量前一端点到先出现的实际最高/最低极值的处理后 K 线跨度；后续次高/次低分型只是较弱端点，不能用端点到次高/次低的整体窗口替代极值跨度。次高/次低相对极值的回撤不得超过此前主波幅的 50%。规则来源为《8月半年课150808 第二课 笔的定义》。
- 修正笔通过每次行情变化后的确定性全量重算更新尾部同类极值。若临时反向端点随后被更极端的同类分型替换，必须重新评估其间曾因距离或价格分离不足而跳过的上一端点同类分型；更极端者替换旧端点，同价保留较早者，禁止因扫描顺序永久丢失候选分型。
- 打横笔需要次级别对称中枢震荡证据；当前独立周期引擎不伪造缺失的次级别证据，因此只保留规则来源，不主观生成。
- 跳空笔要求随后三根K线不回补。指数5分钟阈值1%、30分钟2%；个股5分钟2.5%、30分钟5%。日线、周线、月线不直接按缺口成笔。

## 方向性L1笔中枢

仅使用本周期已确认笔。候选由进入笔 `P0` 和后续方向交替的核心三笔 `P1/P2/P3` 组成。核心按 `ZD=max(low(P1..P3))`、`ZG=min(high(P1..P3))` 计算，并严格要求 `ZD < ZG`。

向上进入要求 `start(P0) < ZD < end(P0)`；向下进入要求 `start(P0) > ZG > end(P0)`，接触边界不算进入。成功后消费四笔，失败右移一笔。矩形只覆盖核心三笔，进入笔作为方向证据保留在矩形外。

该四笔方向定义为产品覆盖规则。它借鉴原文“进入段 a + 中枢 A”的组织方式，但不标记为原文原生定义。

核心形成后固定 `ZD/ZG`。后续笔区间与固定核心严格重合时延伸同一个L1；暂时离开但在独立新中枢确认前重新进入时，外围波动并入原L1并更新 `DD/GG`。`DD/GG` 包含进入笔。低级结构始终保留，不因笔数达到九笔而自动升级。

## 正式递归确认

只有三个连续、交替、共享真实端点且具有反向确认中枢证据的低一级正式走势严格重叠时，才确认父级中枢；两个合格走势生成 `provisional / 2/3` 候选。`extension_3x3` 是符合旧三单位构成的特例标签，`expansion` 是子中枢核心分离且外围未严格分离的路径标签，其余合法组合为 `recursive_three`。标签不替代完成证据，不限制正式低级走势的长度。递归最高 L8。

`formed` 表示已形成；`status=provisional` 表示未结束，`status=confirmed` 表示反向确认已发生。未完成走势绘制当前方向候选极值，同时保留真实尾部；不因回撤反转方向。中断区间仅标记 `sequence_boundary/data_boundary`，不伪造完成。

## 本周期正式走势

本层是产品覆盖规则，不冒充原文完整递归走势。一个中枢构成盘整候选；两个以上严格同向分离的中枢构成同一个趋势：上升要求 `ZD(next) > ZG(previous)`，下降要求 `ZG(next) < ZD(previous)`，边界接触不算趋势。

反向独立中枢是走势结束的唯一正式确认事件；组件分组、三笔完成、延伸数量和数据右边界都不能确认走势结束。走势实际边界回溯到两中枢之间的真实最高或最低笔端点；同价取最早端点。相邻走势方向交替，只共享该端点，不共享整笔。最右侧走势保持 `provisional`，首中枢进入笔之前的笔保留为未归属。任何走势不得跨越行情连续区间。

反向指新中枢进入方向与当前走势相反，独立要求同级核心严格分离（边界接触不算）。不能以中枢位置向下移动或外围扩张替代反向方向。`confirmed_at` 取反向中枢确认事件，不回填极值日期。包含混合关系的中枢序列仍沿用 consolidation 分类，但不宣称是原文单中枢盘整。

人工笔/中枢修订暂时关闭，包括恢复与批量接口；历史记录只读且不参与派生结构。普通画线、矩形与绘图保存保留。

正式层级链路从 L1 笔中枢开始，递归生成各级正式中枢与 `hierarchy_component` 走势。每一级走势只消费连续、交替、共享真实端点的低一级正式单位，不跨行情缺口；最右侧尚未被反向中枢确认的走势保持 `provisional`。图表返回当前页面范围内的全部正式级别中枢和正式走势；日线图的 L1/L2/L3 分别使用日线、周线、月线颜色，周线图的 L1/L2 分别使用周线、月线颜色，分钟级高级中枢只使用本周期稳定明暗变体。跨周期真实递归、背驰和买卖点不进入本版。
