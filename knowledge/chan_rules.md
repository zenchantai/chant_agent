# 各周期笔与方向性 L1 中枢规则

正式版本：`chan-period-center-hierarchy-cache-fingerprint-v13`。

## 运行链路

`本周期K线 -> 包含 -> 严格分型 -> 标准笔/特殊笔 -> 方向性L1笔中枢 -> 本周期走势 -> 同级别分解`

5分钟、30分钟、日线、周线和月线各自读取本周期行情、计算和保存结构。任何周期的数据变化都不会触发其他周期的结构变化。日线 L1/L2/L3 与日线/周线/月线的对应仅用于显示颜色和产品解释，不把日线走势写入周线笔，也不作为跨周期递归输入。

## 普通笔

包含和分型按《读缠论108课札记》第62、65、77课执行。笔采用标准笔：顶底交替，分型不共享处理后K线，中间至少一根独立K线，并要求顶底保持基本方向关系。有包含处理上下文时，顶分型中间K线的高低点均高于底分型中间K线；同类分型保留更极端者，相等时保留较早者。不再要求双方三K区间做双向极值穿透。

## 特殊笔

依据《8月半年课150808 第二课 笔的定义》：

- 次高/次低笔是普通五 K 线标准笔的例外，仅在标准笔不能成立时尝试。四根 K 线条件衡量前一端点到先出现的实际最高/最低极值的处理后 K 线跨度；后续次高/次低分型只是较弱端点，不能用端点到次高/次低的整体窗口替代极值跨度。次高/次低相对极值的回撤不得超过此前主波幅的 50%。规则来源为《8月半年课150808 第二课 笔的定义》。
- 修正笔通过每次行情变化后的确定性全量重算更新尾部同类极值。若临时反向端点随后被更极端的同类分型替换，必须重新评估其间曾因距离或价格分离不足而跳过的上一端点同类分型；更极端者替换旧端点，同价保留较早者，禁止因扫描顺序永久丢失候选分型。
- 打横笔需要次级别对称中枢震荡证据；当前独立周期引擎不伪造缺失的次级别证据，因此只保留规则来源，不主观生成。
- 跳空笔要求随后三根K线不回补。指数5分钟阈值1%、30分钟2%；个股5分钟2.5%、30分钟5%。日线、周线、月线不直接按缺口成笔。

## 方向性L1笔中枢

仅使用本周期已确认笔。候选由进入笔 `P0` 和后续方向交替的核心三笔 `P1/P2/P3` 组成。核心按 `ZD=max(low(P1..P3))`、`ZG=min(high(P1..P3))` 计算，并严格要求 `ZD < ZG`。

向上进入要求 `start(P0) < ZD < end(P0)`；向下进入要求 `start(P0) > ZG > end(P0)`，接触边界不算进入。成功后消费四笔，失败右移一笔。矩形只覆盖核心三笔，进入笔作为方向证据保留在矩形外。

该四笔方向定义和下述两级封顶均为产品覆盖规则。它借鉴原文“进入段 a + 中枢 A”的组织方式，但不标记为原文原生定义。

核心形成后固定 `ZD/ZG`。后续笔区间与固定核心严格重合时延伸同一个L1；暂时离开但在独立新中枢确认前重新进入时，外围波动并入原L1并更新 `DD/GG`。低级结构始终保留，九段 `3+3+3` 或扩张路径满足三个已完成低级走势严格重叠后，另行新增高一级中枢，周期内最高递归到L8。

## 本周期走势与同级别分解

本层是产品覆盖规则，不冒充原文完整递归走势。一个中枢构成盘整候选；两个以上严格同向分离的中枢构成同一个趋势：上升要求 `ZD(next) > ZG(previous)`，下降要求 `ZG(next) < ZD(previous)`，边界接触不算趋势。

反向独立中枢确认前一走势完成，但走势实际边界回溯到两中枢之间的真实最高或最低笔端点；同价取最早端点。相邻走势方向交替，只共享该端点，不共享整笔。最右侧走势保持 `provisional`，首中枢进入笔之前的笔保留为未归属。任何走势不得跨越行情连续区间。

中枢层级链路与同级别分解独立。同级别分解从左到右非重叠消费三个低一级运动，当三段严格重叠即完成一个盘整单元，第4至6段继续形成后续盘整。同级新生中枢可组织为趋势；扩张和延伸只影响层级链路，不回写操作分解边界。
