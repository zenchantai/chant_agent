# 周期内笔、中枢与 L1→L2 晋级规则

正式版本：`chan-period-pen-center-l2-v1`。

本版本把确认笔作为当前周期的最低完成结构单位，先稳定笔和笔中枢，再保留一次 L1→L2 中枢晋级。最终链路为：

```text
行情 -> 包含 -> 分型 -> 确认笔 -> L1 中枢 -> L1 延伸/扩展 -> L2 中枢
```

## 周期策略

- `5`、`30`、`d` 使用 `calculation_profile=pen_centers_l2`，计算确认笔、L1 中枢、L1 延伸/扩展和一次 L1→L2 晋级，`max_level=2`。
- `w`、`m` 使用 `calculation_profile=pen_centers_only`，只计算确认笔、L1 中枢及其延伸/扩展，不生成 L2，`max_level=1`。
- 所有周期都禁用走势分区、走势边界、背驰、结构买卖点和 L2 以上递归。不存在 `Movement`、`Point`、L3 或更高层级。
- 形成中数据只用于独立预览；正式结构继续使用已经确认的行情和确认笔，不能用未来数据补齐证据。

## 行情、分型与笔

- 各周期行情按时间升序去重并校验 OHLC，不跨越数据断点、区间边界或连续流边界。
- 包含关系从左向右处理；向上取高高低高，向下取低低高低，方向由首个非包含关系确定。
- 顶分型中间 K 线高低点严格高于左右 K 线，底分型反之，并在右侧 K 线完成时确认。
- 笔由交替顶底分型构成，不共享分型 K 线，继续沿用当前工程已验证的标准笔、特殊笔、跳空笔和活动尾部修订规则。

## L1 中枢

- L1 中枢的核心由连续、已确认、方向交替且严格重叠的三笔组成：`ZD=max(low1,low2,low3)`，`ZG=min(high1,high2,high3)`，且 `ZD+epsilon<ZG`。
- 方向性核心固定 `ZD/ZG`；同向 Z 单位与核心闭区间接触可形成延伸。`DD/GG` 只取核心第一、第三及已接纳的同向延伸 Z 单位。
- 进入、连接、离开和回试组件保留为上下文证据，不取得 L1 拥有权。L1 的直接拥有单位是笔。
- 核心分离且后续 Z 单位再次接触核心区间时，保留连续性、连接和真实 Z 见证，并生成 `expansion_up` 或 `expansion_down` 中枢关系。
- 中枢候选必须通过确认、连续性、方向、边界、时间和同级所有权校验；已经提交的候选和确认前缀不能被后续滑动窗口替换。

## L1→L2 晋级

- 只有 `pen_centers_l2` 执行晋级；`pen_centers_only` 不生成 `promotion_candidates` 或 `segment_proofs`。
- 晋级只使用 L1 笔、L1 中枢及组件、笔连续性、笔级核心见证和 L1 延伸/扩展证据；晋级接口不接受走势或买卖点输入。
- 三个连续笔原生 `SegmentProof` 共同提供 L2 的真实区间交集；第三段可以是动态证据。缺少有效边界时保留候选或未完成状态，不用包络直接升级。
- L2 使用独立 `family_id`，保留 `decomposition_proof`、`promotion_candidate_revisions`、`segment_proof_revisions`、`child_center_ids` 和 `promoted_into` 父子关系。
- L1 子中枢不因晋级改级或停用；L2 提交后立即停止，不把 L2 作为下一层输入。

## 生命周期与展示

- 中枢修订只追加证据并按时间仲裁旧回试、外部边界和独立后继核心；动态/固定状态、证据时间和边界状态必须可追溯。
- 正式结构响应只包含行情处理、分型、笔、组件、L1/L2 中枢、候选、晋级证据、段证明、关系、问题和级别信息。
- `drawing_objects`、行情数据、用户手工线段和跨周期展示数据不因走势下线而删除；走势与结构买卖点不是正式输入、存储或展示对象。
